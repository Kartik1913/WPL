# WPL Experiment 7 ReactJS

An original React + Vite + Bootstrap lab project demonstrating JSX, components, props, state, events, lifecycle, seven commonly used hooks, `useReducer`, controlled forms, validation, routing, and a light/dark theme.

## Run

1. Install Node.js 18 or newer.
2. In this folder run `npm install`.
3. Run `npm run dev` and open the URL shown by Vite.
4. Use `npm run build` to create a production build.
